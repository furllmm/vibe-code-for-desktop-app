# Desktop UI quality

- Inspect the existing visual language before changing layouts.
- Use consistent spacing, typography, alignment, control sizing, and clear hierarchy.
- Prefer reusable widgets and keep presentation separate from application logic.
- Include useful empty, loading, success, and error states where relevant.
- Respect keyboard navigation, accessible labels, focus visibility, and light/dark theme behavior.
- Preserve explicit user requirements; suggestions must be labeled as optional.
- Verify the preview when possible and report visual checks honestly.
